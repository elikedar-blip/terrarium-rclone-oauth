Privacy Policy

Effective Date: September 2026

1. Overview

This application is a personal, non-commercial backup utility designed strictly to upload system backup files from a private server to the account owner's personal Google Drive.

2. Data Collection & Access

This application requests access to Google Drive strictly to write and read backup files created by the system owner. No personal user data, identifiers, or tracking information are collected, sold, or shared with third parties.

3. Data Storage

All authentication credentials (OAuth tokens) are stored locally on the owner's private server and are never transmitted to any external third-party server.

4. Contact

For any questions regarding this personal application, please contact the repository owner.
